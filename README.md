# Property Listing Website

A Laravel-based property listing platform where owners can post properties and users can browse listings.

## Features

- User authentication
- Property CRUD (Create, Read, Update, Delete)
- Image upload
- Owner dashboard
- Admin panel
- Responsive UI
- Dark mode

## Tech Stack

- Laravel
- Tailwind CSS
- MySQL
- Blade

## Installation

1. Clone repository  
2. Run `composer install`  
3. Run `npm install && npm run dev`  
4. Copy `.env.example` to `.env`  
5. Configure database  
6. Run `php artisan migrate`  
7. Run `php artisan serve`
